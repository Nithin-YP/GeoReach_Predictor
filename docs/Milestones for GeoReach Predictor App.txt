Milestone: Database Models and Schema Setup
✅ Expected Time: 5–7 days
📊 Completion Progress: 15%
Tasks:
   * Create models for:

      * User (id, username, email, password_hash, role, created_at, is_active)

      * PredictionRequest (id, user_id, product_type, product_luxury, target_audience, price, region, request_timestamp)

      * PredictionResult (id, prediction_request_id, predicted_reach, success_probability, model_confidence, created_at)

      * Cluster (id, prediction_result_id, latitude, longitude, cluster_label, population_density, avg_income, employment_rate, interest_index)

      * Dataset (id, name, source, upload_date, last_updated, feature_list, record_count)

         * Define relationships:

            * User 1 → n PredictionRequest

            * PredictionRequest 1 → 1 PredictionResult

            * PredictionResult 1 → n Cluster

               * Ensure Admin user is pre-created programmatically via a Django management script.
