🔒 CSRF Protection Test Page

This page tests CSRF (Cross-Site Request Forgery) protection for the GeoReach Predictor application.

Test 1: Check CSRF Token

This checks if a CSRF token can be retrieved from cookies or the page.

Test 2: Form Submission Test

This tests if forms are properly protected with CSRF tokens.

{% csrf_token %}

Test 3: AJAX POST Request

This tests if AJAX requests include proper CSRF tokens.

Test 4: Cookie Check

This displays all cookies to verify CSRF cookie is set.

📋 Instructions

  1. Make sure Django development server is running: python manage.py runserver
  2. Click each test button in order
  3. Green results = CSRF is working correctly
  4. Red results = CSRF configuration issue
  5. Open browser DevTools (F12) to see detailed network requests
